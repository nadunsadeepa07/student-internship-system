## 📌 Project Overview

The **Student Internship Management System (SIMS)** is a web-based internship management platform designed to simplify the process of connecting students with companies and managing internship opportunities.

The system allows administrators to manage students, companies, internship posts, applications and user approvals.

Students can register, search and filter internship opportunities, view company and internship details, apply for internships, track application status, manage their profiles, and create professional CVs.

Companies can securely log in, manage their profiles, post internship opportunities, view applications and manage student applicants.

---

# 🎓 Student Internship Management System

A full-stack **Student Internship Management System** developed using React.js, Node.js, Express.js, MongoDB, Tailwind CSS and JavaScript.

- 👥 Student Management
